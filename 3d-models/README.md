
# Shot Timer - 3D Baskı Kutusu

Bu klasörde Shot Timer projesi için özel olarak tasarladığımız 3D baskı kutusu bulunmaktadır.

## 3D Model Dosyası

**ShotTimer.3mf**

Bu dosya, Shot Timer kutusunun bütün parçalarını tek bir 3MF projesi içerisinde barındırır.

## Kullanım

1. `ShotTimer.3mf` dosyasını indirin.
2. Bambu Studio, OrcaSlicer veya 3MF destekleyen uygun bir dilimleme programında açın.
3. Yazıcınıza ve kullandığınız filamente göre baskı ayarlarını kontrol edin.
4. Parçaları dilimleyerek 3D yazıcınızda üretin.

## Açıklama

Kutu, Shot Timer cihazının elektronik bileşenlerini muhafaza etmek amacıyla özel olarak tasarlanmıştır.

Not: Baskı öncesinde modelin ölçeğini, parça yerleşimini ve dilimleme ayarlarını kontrol edin.
